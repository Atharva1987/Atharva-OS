Atharva.OS
hey, this is my personal site and blog where i write about code, systems, and tech stuff i'm building.

i wanted something super clean and fast, so i built Atharva.OS without using any massive frameworks. just simple web stuff, a command palette, and a dark mode.

Tech Stack:
HTML5 — simple, semantic structure

CSS3 — custom variables, CSS grid, dark/light theme, responsive layout

JavaScript — handles the search bar, filter tabs, article modals, and theme toggle

Python — small scripts for automation

Git — version control

Features:
Dark/Light Mode: smooth theme toggle that doesn't hurt your eyes

Command Palette (⌘K / Ctrl+K): quick search to jump to posts fast

Post Reader Modal: read full blog posts right on the page without reloading

Tag Filtering: filter posts by topics like Engineering or System Design

Mobile Friendly: works fine on phones, tablets, or desktop
