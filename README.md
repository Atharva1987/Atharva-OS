# Atharva.OS

> A minimalist, high-end personal engineering blog and digital workspace.

**Atharva.OS** is a personal portfolio and blog designed with an editorial aesthetic inspired by modern developer platforms. Built with clean, framework-free web technology, it showcases technical writing, architecture notes, and personal thoughts.

---

## ⚡ Tech Stack

- **HTML5** — Semantic, accessible document structure
- **CSS3** — Custom properties, CSS grid layout, responsive typography, and themes
- **JavaScript (ES6+)** — Client-side search, filtering, dynamic modal rendering, and theme toggling
- **Python** — Backend scripts and automation tools
- **Git** — Version control and project history

---

## ✨ Features

- **Editorial UI/UX**: Clean dark/light theme switching with smooth transitions.
- **Interactive Command Palette (`⌘K` / `Ctrl+K`)**: Fast navigation and article quick-access.
- **Article Reader Modal**: In-page modal viewer for deep-dive technical blog posts.
- **Real-time Filtering**: Filter blog posts by category (Engineering, Architecture, System Design).
- **Responsive Layout**: Designed to work across mobile, tablet, and desktop viewports.

## 🚀 Getting Started

### Local Development

1. **Clone the repository:**
   bash
   git clone [https://github.com/your-username/Atharva.OS.git](https://github.com/your-username/Atharva.OS.git)

2. **Navigate to the directory:**
  bash
  cd Atharva.OS




3. **Open `index.html` in your browser:**
* Double-click `index.html`, or
* Use a local server extension (e.g., Live Server in VS Code).
